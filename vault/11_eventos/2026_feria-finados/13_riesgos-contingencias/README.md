# Riesgos y contingencias

Mantiene el registro único de riesgos, indicadores tempranos, mitigaciones, responsables y planes de respuesta. Incluye clima, seguridad, salud, aforo, programación, reputación, ventas, proveedores, energía, conectividad, movilidad y finanzas.

Cada riesgo crítico debe tener dueño y respuesta ensayada. En emergencias, prevalecen los planes aprobados por seguridad y las autoridades competentes.
