# Expositores

Gestiona segmentación, oferta, precios, prospección, selección, contratos, pagos, asignación de espacios, requisitos técnicos, onboarding, servicio y satisfacción.

## Entregables mínimos

- Inventario y capacidad de espacios aprobado por producción/seguridad.
- Tarifario, beneficios, términos y política de selección.
- Embudo de captación con dueño de cada oportunidad.
- Expediente de onboarding y manual del expositor.
- Control de pagos y documentos enlazado al sistema autorizado.
- Encuesta y reporte final.

No guardes documentos de identidad ni datos bancarios en este repositorio.
