# Permisos y seguridad

Centraliza requisitos legales y municipales, aforo, seguros, gestión de riesgos, bomberos, salud, alimentos, alcohol si aplica, control, evacuación, emergencias, menores, accesibilidad y coordinación con autoridades.

## Entregables mínimos

- Matriz de permisos con autoridad, requisito, dueño y fecha límite.
- Aforo y planos aprobados.
- Plan integral de seguridad y emergencias.
- Recursos médicos, evacuación y comunicaciones.
- Protocolos de incidentes y protección de públicos vulnerables.
- Simulacro y acta de preparación.

La seguridad tiene autoridad para bloquear una apertura o actividad que no cumpla criterios críticos.
