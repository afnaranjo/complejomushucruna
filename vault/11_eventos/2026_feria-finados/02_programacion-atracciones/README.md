# Programación y atracciones

Controla artistas, espectáculos, actividades culturales, deportivas, familiares y comerciales; horarios, escenarios, contratos, necesidades técnicas y estado de confirmación.

## Regla pública

Marketing solo comunica elementos con estado `confirmado`, aprobación registrada y condiciones contractuales verificadas.

## Entregables mínimos

- Inventario de propuestas y criterios de selección.
- Programación maestra sin cruces de recursos.
- Contratos y riders enlazados desde el almacenamiento autorizado.
- Plan B por cancelación, clima o falla técnica.
- Ficha de comunicación aprobada para cada atracción.
