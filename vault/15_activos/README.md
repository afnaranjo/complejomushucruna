# Activos

Biblioteca de recursos aprobados y reutilizables: logos, iconos, fotografías, videos, música, plantillas y documentos maestros. Cada activo debe tener una ficha con dueño, versión, usos permitidos, restricciones y licencia.

Los borradores pertenecen a `10_creatividad/` o a su campaña. Si el archivo es demasiado pesado para Git, registra aquí el enlace de la ubicación oficial y el checksum cuando sea relevante.
