# Campañas

Una campaña conserva un solo expediente durante todo su ciclo:

```text
AAAA-MM_nombre-corto/
├── 00_brief.md
├── 01_plan.md
├── 02_medicion.md
├── 03_creatividad/
├── 04_publicaciones-y-enlaces.md
└── 05_reporte-cierre.md
```

Muévela entre `planificadas/`, `activas/` y `cerradas/` sin duplicarla. Usa las plantillas de `00_gobernanza/plantillas/`.
