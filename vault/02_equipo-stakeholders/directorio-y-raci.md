# RACI mínimo

R = ejecuta · A = aprueba y responde por el resultado · C = consultado · I = informado.

| Decisión | Negocio | Marketing | Ventas | Operaciones | Creatividad | Datos |
|---|---|---|---|---|---|---|
| Objetivos y presupuesto anual | A | R | C | C | I | C |
| Lanzar campaña | A | R | C | C | R | C |
| Cambiar precio u oferta | A | C | R | C | I | C |
| Publicar pieza | I | A | C | C | R | I |
| Modificar tracking/KPI | I | A | C | I | I | R |
| Confirmar capacidad de evento | I | C | C | A/R | I | I |
| Aprobar reporte de cierre | I | A | C | C | I | R |

> Reemplaza los roles por nombres únicamente después de confirmar responsabilidades con el equipo.
