# Fortalezas, experiencias positivas y eventos destacados

Esta carpeta conserva únicamente lo bueno que las personas y las fuentes públicas reconocen del Complejo Intercultural y Deportivo Mushuc Runa: fortalezas, experiencias positivas, impacto favorable y aprendizajes de eventos anteriores que conviene proteger.

Es una carpeta hermana, separada de [[../01_reputacion-riesgos-y-voz-publica/README|Reputación, riesgos y voz pública]]. No reemplaza ni suaviza los problemas registrados allí; equilibra la memoria del proyecto para que las mejoras no destruyan lo que el público ya valora.

## Si abres un chat desde esta carpeta

1. Abre [[00_empieza-aqui|Empieza aquí para contar algo bueno]].
2. Copia el texto indicado y abre una tarea nueva de Codex.
3. Cuéntale la observación positiva, evento o evidencia que quieres conservar.
4. El agente debe trabajar solo aquí y no recorrer el resto del vault, salvo los registros mínimos obligatorios del proyecto.

## Principio de calidad

Una afirmación favorable no se considera oficial solo porque aparezca en prensa, redes, reseñas o páginas del organizador. Cada nota debe indicar qué está verificado, qué es percepción, qué es una declaración interesada y qué falta confirmar internamente.
