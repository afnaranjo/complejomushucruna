# Aportes internos positivos

Guarda aquí las cosas buenas que el equipo, visitantes, expositores, aliados o proveedores recuerdan del complejo y de sus eventos.

## Uso rápido

1. Abre el chat desde la carpeta `02_reputacion-fortalezas-y-voz-positiva/`.
2. Indica al agente que lea el `AGENTS.md` local y trabaje solo dentro de esta carpeta.
3. Describe qué ocurrió, en qué evento o fecha, quién puede confirmarlo y qué evidencia existe.
4. Usa [[plantilla-observacion-positiva|la plantilla]] para conservar la trazabilidad.

## Privacidad

- No incluyas nombres de trabajadores o visitantes si no son indispensables.
- No pegues conversaciones privadas, teléfonos, cédulas ni fotografías sin autorización.
- Un recuerdo del equipo se registra como `reporte interno` hasta que exista evidencia o confirmación del responsable.
- Una felicitación aislada no representa a todo el público.
