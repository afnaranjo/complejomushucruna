# Reportes internos anonimizados

Aquí se sintetizan problemas que el personal conoce y que no aparecen públicamente. No se guardan nombres, capturas privadas ni acusaciones identificables.

## Cómo recibir un reporte

1. Escucha sin prometer una conclusión.
2. Pregunta qué ocurrió, cuándo, dónde, con qué frecuencia y qué evidencia existe.
3. Separa observación directa, relato de terceros e interpretación.
4. Elimina nombres y detalles que puedan identificar a la persona.
5. Clasifica evidencia y severidad con la metodología oficial.
6. Escala de inmediato riesgos críticos por el canal adecuado.
7. Registra responsable y siguiente acción; no dejes el reporte abandonado.

## Regla de no represalia

El reporte se utiliza para corregir sistemas y proteger la feria. No se usa para buscar culpables ni castigar a quien advierte un problema de buena fe.
