# Empieza aquí para contar un problema

Esta es la puerta de entrada para que el personal cuente fallas, reclamos, riesgos, malas experiencias o problemas que podrían afectar al Complejo Mushuc Runa y a la Feria de Finados 2026.

No necesitas escribir un informe ni saber dónde clasificarlo. Cuéntalo con tus propias palabras y la IA te hará preguntas sencillas para convertirlo en un reporte ordenado y anonimizado.

## Texto para abrir el chat

Copia y pega únicamente este mensaje en una tarea nueva de Codex dentro de este proyecto:

> Lee primero y completamente `AGENTS.md` y `vault/AGENTS.md`. Después lee `vault/05_audiencias-investigacion/01_reputacion-riesgos-y-voz-publica/02_reportes-internos/00_empieza-aqui.md` y comienza la entrevista. Quiero registrar una observación interna.

Después puedes empezar así:

> Lo que está pasando es...

## Lo que hará la IA

1. Escuchará el relato sin juzgar ni buscar culpables.
2. Hará una pregunta breve a la vez para entender qué ocurrió, cuándo, dónde, con qué frecuencia y qué impacto tiene.
3. Distinguirá entre algo observado directamente, un relato de otra persona, una opinión y una hipótesis.
4. Eliminará nombres y cualquier detalle que permita identificar al reportante.
5. Creará un archivo independiente por problema usando [[plantilla-reporte-interno|la plantilla oficial]].
6. Clasificará de forma preliminar la evidencia y la severidad, sin presentar el relato como un hecho comprobado.
7. Guardará el reporte dentro de esta carpeta y realizará el cierre de Git establecido en las reglas del proyecto.

## Reglas para quien reporta

- No escribas nombres de trabajadores, denunciantes ni personas acusadas.
- No pegues cédulas, teléfonos, correos privados, contraseñas, capturas de conversaciones privadas ni documentos personales.
- Explica hechos o experiencias concretas: qué ocurrió, dónde, cuándo, con qué frecuencia y a quiénes afecta.
- Puedes decir que no sabes o que algo es solo una sospecha. La IA lo dejará marcado correctamente.
- Si son varios problemas diferentes, cuéntalos por separado para crear un reporte por tema.

> [!danger] Riesgos urgentes
> Un peligro inmediato para la vida o seguridad, abuso, acoso, fraude o posible incumplimiento legal debe comunicarse también de inmediato al responsable directivo o profesional correspondiente. No debe quedar atendido únicamente mediante una nota en GitHub u Obsidian.

## Alcance de acceso

El personal puede trabajar únicamente desde esta carpeta para entregar sus observaciones. La IA sí debe leer los archivos de gobierno obligatorios y actualizar la memoria o bitácora exigida por `AGENTS.md`, pero no necesita explorar otras áreas para recibir el relato.
