# Reputación, riesgos y voz pública

Esta es la sección oficial para conservar lo que puede afectar al Complejo Mushuc Runa y a Feria de Finados 2026: críticas públicas, fallas históricas, fricciones de visitantes/expositores, problemas internos reportados y señales que requieren investigación.

No es una carpeta para atacar personas ni recopilar rumores. Su propósito es detectar problemas temprano, verificar evidencia, asignar responsables y mejorar.

## Regla de seguridad y justicia

- No guardes nombres de trabajadores, denunciantes o personas acusadas.
- No conviertas una opinión en un hecho comprobado.
- No uses esta sección para represalias ni evaluaciones personales.
- Un riesgo inmediato para vida, seguridad, abuso, fraude o incumplimiento legal se escala por el canal directivo/profesional correspondiente; no se deja solamente como nota de GitHub.
- No subas documentos de identidad, conversaciones privadas, grabaciones sin autorización ni datos personales sensibles.

## Flujo

```text
señal → registro → clasificación → verificación → prioridad → responsable → acción → evidencia de cierre
```

Cada hallazgo debe indicar fuente, fecha, alcance, nivel de evidencia, afectación, frente dueño y estado.

## Cobertura pendiente

La investigación pública inicial no puede leer todo lo que existe. Faltan comentarios no indexados de Facebook, Instagram y TikTok; mensajes directos, WhatsApp, llamadas, encuestas, reclamos formales, reportes de expositores y conocimiento del personal. Esas fuentes se incorporarán con acceso autorizado y datos anonimizados.
