# Gobernanza

Contiene las reglas que mantienen coordinado al equipo: arquitectura documental, decisiones transversales, convenciones y plantillas. Solo se modifica cuando una necesidad recurrente demuestra que la estructura actual no es suficiente.

No almacenes aquí estrategia, campañas ni entregables creativos.
